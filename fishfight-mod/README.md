# Fish Fight! 釣りバトル

ミニゲームで魚を釣り上げて、1匹ずつ違うステータスを持つ魚同士でプレイヤー対戦するMinecraft Modです。
ときどき魚からいきなり腕が生えます。

- Minecraft **1.21.1** / **Fabric**（Fabric API が必要）

## 遊び方

### 1. 釣る
普通の釣り竿で釣りをして、ウキが沈んだら引きます。
85% の確率で釣りミニゲームが始まります（残りはバニラの釣果）。

- **スペース長押し（またはクリック長押し）** で緑のゾーンが上がる、離すと落ちる
- 魚がゾーンの中にいる間、右のゲージが溜まる → 満タンで釣り上げ
- ゲージが空になるか ESC で逃げられる
- レアな魚ほど暴れて、ゾーンも小さい
- 「腕付き」の魚はミニゲームの途中で **腕が生えて** 暴れ出す

海バイオームでは海の魚、それ以外では淡水の魚が釣れます。「宝釣り」エンチャントでレアが出やすくなります。

### 2. 魚のステータス
釣った魚は1匹ずつ違う個体です。

| 項目 | 内容 |
|---|---|
| 種類 | コイ / サバ / フグ / ピラニア / ナマズ / マグロ / カジキ / サメ / リュウグウノツカイ / シーホース / シーラカンス |
| レア度 | コモン★ 〜 ミシック✦（ステータス最大2倍） |
| 体長・重さ | レアほど大きくなりやすい |
| HP・攻撃・防御・素早さ・会心率 | 種類 × レア度 × 大きさ × 性格 × 体質で決まる |
| 性格 | がんこ / おくびょう / のんき / ずぶとい / せっかち / きまぐれ / まじめ |
| 特異体質 | 腕付き / 脚付き / 巨大 / 極小 / 黄金 / マッチョ / 電気 / トゲトゲ |
| 勝利数 | 対戦で勝つと増える |

アイテムにカーソルを合わせるか `/fishfight info` で確認できます。

### 3. 戦わせる
1. 魚を手に持って相手プレイヤーを **右クリック**（または `/fishfight challenge <名前>`）
2. 相手も魚を持って、チャットの **[受けて立つ]** をクリック（または `/fishfight accept`）
3. 2人の間にお互いの魚が **モブとして** 出てきて、3・2・1のあと自分で戦い始める

魚は1匹ずつ独立したモブで、相手を追いかけて勝手に攻撃します（プレイヤーは見守るだけ）。

- **陸で脚がない魚はピチピチ跳ねる**：相手の方へ跳ねて近づくが、攻撃が外れやすい
- **脚がある魚は普通に歩いて戦う**：きっちり近づいて確実に攻撃
- **水の中ではすいすい泳ぐ**：戦う場所によって有利不利が変わる
- 素早さが高いほど攻撃の間隔が短い。HPが0になった方の負け（90秒たったら残りHPの割合で判定）
- 周りのプレイヤーも観戦できる（ボスバーでHP表示）

### 4. スキル（自動発動）
魚によってスキルを持っていたり持っていなかったりします（レアほど多く持てる、最大3つ）。条件を満たすと勝手に発動します。

| スキル | 発動条件 | 効果 |
|---|---|---|
| 腕生え | HPが50%以下 | ムキムキの腕が生えて攻撃力1.5倍、パンチ連打 |
| 脚生え | 陸で3秒跳ね続ける | 脚が生えて、もう跳ねずに歩いて戦える |
| 巨大化 | HPが30%以下 | 体が1.4倍に、攻撃力アップ |
| 再生 | HPが35%以下（1回） | HPを35%回復 |
| 逆上 | HPが40%以下 | 攻撃が速くなる |
| 放電 | 近くに相手（8秒ごと） | 電撃ダメージ＋しびれ |
| 突進 | 相手が遠い（7秒ごと） | 突っ込んで大ダメージ＋吹き飛ばし |
| 水鉄砲 | 相手が遠い（5秒ごと） | 離れた相手に水を発射 |
| ふくらむ | 攻撃を受けた時 | ふくらんで防御2倍 |
| 根性 | 倒れる攻撃（1回） | HP1で踏みとどまる |

種類ごとに覚えやすいスキルがあります（フグ→ふくらむ、ナマズ→放電、マグロ・カジキ→突進、シーラカンス→根性・脚生え など）。
特異体質の「腕付き」「脚付き」の魚は最初から腕・脚があります。

### 5. 固有能力
種類によっては、必ず持っている固有能力があります。

- **サメ「シャークマン覚醒」**：HPが2割を切ると、宙に浮いて回転しながら光り、雷鳴とともに **ムキムキの人型（サメ頭・海パン）** に覚醒する。攻撃力2倍・素早さアップ・HP少し回復。覚醒前にとどめを刺されそうになっても、HP1で踏みとどまって覚醒する
- **シーホース「馬力」**：見た目は魚ではなく **普通の馬**（体長20cm前後なのに重さ約480kg）。陸では馬が横倒しのまま4本脚をジタバタさせて跳ねる。攻撃が当たると相手を大きく蹴り飛ばす。脚生えが発動すると「脚が生えた！」と言いながら馬として立ち上がる

1人で試すときは `/fishfight practice` で野生の魚と練習試合ができます。

## コマンド

| コマンド | 説明 |
|---|---|
| `/fishfight` または `/ff` | ヘルプ |
| `/fishfight challenge <プレイヤー>` | 対戦を申し込む |
| `/fishfight accept` / `deny` | 申し込みを受ける / 断る |
| `/fishfight practice [種類] [レア度] [体質・スキル…]` | 野生の魚と練習試合（相手を指定もできる） |
| `/fishfight info` | 持っている魚のステータス |
| `/fishfight give [種類] [レア度] [体質・スキル…]` | （OP）魚をもらう。例: `/fishfight give tuna rare arm_sprout leg_sprout` |

## ビルド

```sh
./gradlew build
```

ビルドには **JDK 25** が必要です（Fabric Loom 1.19 の要件。出来上がる jar は Java 21 で動きます）。

`build/libs/fishfight-1.0.0.jar` を `mods` フォルダに入れてください（Fabric API も必要）。
GitHub に push すると Actions が自動でビルドし、jar を Artifacts からダウンロードできます。
