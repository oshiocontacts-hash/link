# Fish Fight! 釣りバトル

ミニゲームで魚を釣り上げて、1匹ずつ違うステータスを持つ魚同士でプレイヤー対戦するMinecraft Modです。
ときどき魚からいきなり腕が生えます。

- Minecraft **1.21.1** / **Fabric**（Fabric API が必要）

## 遊び方

### 1. 釣る
普通の釣り竿で釣りをして、ウキが沈んだら引きます。
85% の確率で釣りミニゲームが始まります（残りはバニラの釣果）。

- **スペース長押し（またはクリック長押し）** で緑のゾーンが上がる、離すと落ちる
- 魚がゾーンの中にいる間、右のゲージが溜まる → 満タンで釣り上げ
- ゲージが空になるか ESC で逃げられる
- レアな魚ほど暴れて、ゾーンも小さい
- 「腕付き」の魚はミニゲームの途中で **腕が生えて** 暴れ出す

海バイオームでは海の魚、それ以外では淡水の魚が釣れます。「宝釣り」エンチャントでレアが出やすくなります。

### 2. 魚のステータス
釣った魚は1匹ずつ違う個体です。

| 項目 | 内容 |
|---|---|
| 種類 | コイ / サバ / フグ / ピラニア / ナマズ / マグロ / カジキ / サメ / リュウグウノツカイ / シーラカンス |
| レア度 | コモン★ 〜 ミシック✦（ステータス最大2倍） |
| 体長・重さ | レアほど大きくなりやすい |
| HP・攻撃・防御・素早さ・会心率 | 種類 × レア度 × 大きさ × 性格 × 体質で決まる |
| 性格 | がんこ / おくびょう / のんき / ずぶとい / せっかち / きまぐれ / まじめ |
| 特異体質 | 腕付き / 脚付き / 巨大 / 極小 / 黄金 / マッチョ / 電気 / トゲトゲ |
| 勝利数 | 対戦で勝つと増える |

アイテムにカーソルを合わせるか `/fishfight info` で確認できます。

### 3. 戦わせる
1. 魚を手に持って相手プレイヤーを **右クリック**（または `/fishfight challenge <名前>`）
2. 相手も魚を持って、チャットの **[受けて立つ]** をクリック（または `/fishfight accept`）
3. 2人の間に魚が出現してオートバトル開始！

- 素早さが高いほど多く行動する
- 種類ごとの必殺技（サメの「ジョーズ」、サバの「サバ読み」、フグの「ふくらむ」など）
- **バトル中、追い詰められた魚からいきなり腕が生えて**「オラオララッシュ」「アッパーカット」を使い出す（攻撃力1.4倍）
- たまに脚も生える
- 電気体質はしびれさせ、トゲトゲ体質は反撃ダメージ、シーラカンスは1回だけ根性で耐える
- 周りのプレイヤーも観戦できる（ボスバーでHP表示）

1人で試すときは `/fishfight practice` で野生の魚と練習試合ができます。

## コマンド

| コマンド | 説明 |
|---|---|
| `/fishfight` または `/ff` | ヘルプ |
| `/fishfight challenge <プレイヤー>` | 対戦を申し込む |
| `/fishfight accept` / `deny` | 申し込みを受ける / 断る |
| `/fishfight practice` | 野生の魚と練習試合 |
| `/fishfight info` | 持っている魚のステータス |
| `/fishfight give [種類] [レア度] [体質]` | （OP）魚をもらう。例: `/fishfight give shark mythic arms` |

## ビルド

```sh
./gradlew build
```

`build/libs/fishfight-1.0.0.jar` を `mods` フォルダに入れてください（Fabric API も必要）。
GitHub に push すると Actions が自動でビルドし、jar を Artifacts からダウンロードできます。
